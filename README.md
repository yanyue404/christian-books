# Christian Books 📖 | 基督徒必读经典书单

一个专注于**改革宗（Reformed）神学**与**福音派基督徒**灵命建造的书籍推荐仓库。

这里收集了从宗教改革时期到当代的优质基督教著作，特别推荐**已故伟大神学家**与**当代忠实牧师/神学家**的作品，帮助信徒更深认识上帝、圣经与基督徒生活。

> "要以基督耶稣的心为心。"（腓立比书 2:5）
> "你们要尝尝主恩的滋味，便知道祂是美善。"（诗篇 34:8）

## 项目目的

- 为基督徒提供系统化的阅读指引，从入门到进深。
- 聚焦**改革宗传统**（Calvinistic/Reformed Theology），同时兼顾广义福音派优秀作品。
- 鼓励信徒通过阅读经典，装备自己、服事教会、荣耀上帝。

**欢迎贡献**：如果您有其他优质推荐（优先改革宗或正统福音派），欢迎提交 Pull Request 或 Issue！

## 每日读经计划（Bible Reading Plans）

持续、系统地阅读圣经是基督徒灵命成长的根基。以下推荐两种经典读经法：

### 麦琴读经法（M'Cheyne Bible Reading Plan）

由苏格兰牧师**罗伯特·麦琴 (Robert Murray M'Cheyne, 1813–1843)** 设计，是改革宗传统中最广泛使用的读经计划之一。

**特点**：

- 每天阅读 **4 章**（分家庭敬拜 2 章 + 个人灵修 2 章）
- 一年内通读旧约 **1 遍**，新约和诗篇 **2 遍**
- 兼顾旧约历史、诗歌智慧、先知书与新约，避免单调

**每日安排**：

| 栏目 | 内容 | 用途 |
|------|------|------|
| 第一栏 | 创世记 → 申命记（摩西五经 + 历史书） | 家庭敬拜 |
| 第二栏 | 诗篇 → 玛拉基（诗歌 + 先知书） | 家庭敬拜 |
| 第三栏 | 马太福音 → 启示录（新约） | 个人灵修 |
| 第四栏 | 创世记 → 启示录（通读全圣经） | 个人灵修 |

**建议**：

1. 每天固定时间、固定地点阅读，养成习惯
2. 先祷告求圣灵开启心眼，再开始阅读
3. 若落后不必焦虑，跳到当天进度继续即可
4. 可搭配笔记本记录感动和疑问

### 福音 365 读经法

一种以**基督为中心**的通读计划，强调在每一卷书中看见福音的线索与基督的影子。

**特点**：

- 每天 **3–4 章**，一年通读整本圣经
- 按照圣经正典顺序阅读，把握救赎历史脉络
- 着重引导读者思考：**这段经文如何指向基督？如何与福音相关？**

**阅读方法**：

每天读经时，用以下四个问题引导默想：

1. **这段经文揭示了上帝怎样的属性？**（认识神）
2. **这段经文揭示了人怎样的光景？**（认识罪）
3. **这段经文如何指向基督和祂的救赎？**（认识福音）
4. **这段经文如何呼召我回应？**（活出信仰）

**建议**：

1. 不要急于"赶进度"，宁可少读一章也要认真默想
2. 旧约中留意预表、应许与盟约如何在基督里成就
3. 新约中留意恩典如何改变生命、教会如何回应福音
4. 可以配合一本好的读经指引（如 D.A. Carson《为爱上帝》）

### 读经的正确心态

> "你的话是我脚前的灯，是我路上的光。"（诗篇 119:105）

- **不是任务，而是相遇** —— 读经不是打卡，而是与永生上帝面对面
- **不是知识，而是生命** —— 目标不仅是"读完"，而是被真理改变
- **不是孤立，而是团契** —— 鼓励在教会小组中分享读经收获
- **不是靠自己，而是靠圣灵** —— 每次翻开圣经前先祷告，求圣灵光照
- **坚持胜过完美** —— 中断了就重新开始，不要放弃
