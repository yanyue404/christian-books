# 简介与目录

本目录是仓库的导读导航。每本书一份 Markdown：简介、目录、依据。中文章题优先采用通行译本，并与英文原题对照。

**未写导读（注释类，按约定跳过）：**

- 《希伯来书注释》— 加尔文
- 《摩根解经丛卷·希伯来书》— 坎伯·摩根

《圣灵论（繁体）》与简体为同一书，见 [圣灵论](圣灵论.md)。《治死信徒身上的罪》与《对罪的治死》为同一论著，见 [对罪的治死](对罪的治死.md)。

不同译本对章题的措辞会略有出入，结构以原著为准。
